# API-тестирование «Яндекс.Самокат»
Здесь собраны артефакты тестирования бэкенда приложения.

**Что внутри:**
* **Checklist_API.md** — чек-лист проверки эндпоинтов.
* В документе представлены:
    * Проверка создания заказа (`POST /orders`).
    * Проверка получения заказа по трек-номеру (`GET /orders/track`).
    * Проверка отмены заказа (`PUT /orders/cancel`).
    * Проверка удаления курьера (`DELETE /courier/:id`).

**Ключевые проверки:**
* Проверка корректности HTTP-кодов ответов (200, 201, 400, 404).
* Валидация структуры JSON.
* Проверка негативных сценариев.
* Проверка бизнес-логики.
