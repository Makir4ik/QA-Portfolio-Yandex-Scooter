# Чек-лист тестирования API «Яндекс.Самокат»

**Инструменты:** Postman.
**Базовый URL:** `https://qa-scooter.praktikum-services.ru`

## Проверенные эндпоинты:
1. `POST /api/v1/orders` — Создание заказа.
2. `GET /api/v1/orders/track` — Получение заказа по его номеру.
3. `PUT /api/v1/orders/cancel` — Отмена заказа.
4. `DELETE /api/v1/courier/:id` — Удаление курьера.
