# Баг-репорты «Яндекс.Самокат»
Здесь собраны сводные данные о найденных дефектах в веб и мобильном приложении.

**Что внутри:**
* **Bug_Reports.md** — таблица и карточки баг-репортов.
* В документе представлены:
    * Подробные баг-репорты с шагами воспроизведения, ожидаемым и фактическим результатом.
    * Сводная таблица дефектов с указанием Severity (Серьезность) и Priority (Приоритет).

**Ключевые проверки (найденные баги):**
* Баги бизнес-логики (например, отмена заказа, когда курьер уже в пути).
* Ошибки валидации форм (пропуск недопустимых символов, например, адрес из одних цифр).
* UI/UX дефекты (проблемы с переносом строк длинных текстов, опечатки в системных сообщениях).
