# Веб-тестирование «Яндекс.Самокат»

Здесь собраны артефакты тестирования веб-приложения.

## Что внутри:
*   **2026 Алексей Бирюков — диплом_Инженер по тестированию.pdf** — полный отчет с чек-листами и таблицами валидации.
*   В документе представлены:
    *   Чек-лист на экран «Статус заказа» (включая UI, логику статусов, работу кнопок).
    *   Таблица валидации полей (Имя, Фамилия, Адрес, Телефон) с применением граничных значений и классов эквивалентности.
    *   Оформленные баги вне тестовой документации (исследовательское тестирование).

## Ключевые проверки:
*   Проверка цепочки статусов заказа (от «Самокат на складе» до «Время аренды кончилось»).
*   Проверка модальных окон (отмена заказа, закрытие по клику вне окна, по кнопке Escape).
*   Проверка отображения длинных текстов (перенос строк, наезжание элементов).
